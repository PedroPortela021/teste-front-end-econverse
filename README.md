# React + TypeScript + Sass

## Style Guide (tokens)

Os tokens globais ficam em `src/styles/tokens.scss`.

- Fonte base: `Poppins`
- Tamanhos: `12, 14, 16, 20, 32, 40, 48`
- Cores:
  - `#3442B5`
  - `#3019B2`
  - `#F7CA11`
  - `#271C47`
  - `#3F3F40`
  - `#9F9F9F`
  - `#FFFFFF`

Use sempre os aliases semanticos (ex.: `--color-text-primary`, `--color-brand-primary`) em vez de hex direto nos componentes.
